# 🌈 Burçin'in Sihirli Gökkuşağı Maceraları (BurcinGame) 🚀

Kızım **Burçin** için özel olarak hazırlanmış, eğlence ve öğrenme amaçlı geliştirilmiş neşeli bir **2D Android TV Platform Oyunu** denemesi! 🎉

---

## 📖 Proje Hakkında

Bu proje, bir babanın kızını tebessüm ettirmek ve birlikte keyifli vakit geçirmek amacıyla geliştirdiği tatlı bir deneme projesidir. 

**"Burçin'in Sihirli Gökkuşağı Maceraları"**, renkli platformlar, toplanabilir yıldızlar ve sürprizlerle dolu bölümlerden oluşur. Hem büyük ekranda (Android TV / Mi Box) televizyon kumandasıyla hem de dokunmatik ekranlı mobil cihazlarda kolaylıkla oynanabilir şekilde tasarlanmıştır.

---

## ✨ Öne Çıkan Özellikler

* 📺 **Android TV & Kumanda (D-Pad) Uyumluluğu:** Mi Box, Android TV ve tüm D-Pad kumandalarla %100 uyumlu yön tuşu odaklanma (Focus Engine) mekanizması.
* 🎨 **Jetpack Compose Arayüzü:** Modern Android UI kütüphanesi olan Jetpack Compose ve Compose Canvas kullanılarak oluşturulmuş akıcı grafikler ve animasyonlar.
* 🏃 **2D Platformer Fizik Motoru:** Zıplama mekaniği, yerçekimi hesaplamaları, platform çarpışma tespiti (Collision Detection) ve dinamik kamera takibi.
* 🗺️ **Bölüm Seçimi & Skor Sistemi:** Farklı zorluk seviyeleri, toplanabilir eşyalar, skor takibi, **Bölüm Tamamlandı (Victory)** ve **Yeniden Dene (Game Over)** ekranları.
* ⚙️ **C++ / NDK Altyapısı:** Yüksek performans gerektiren grafik renderer katmanı için C++ ve CMake entegrasyonu.

## 🎮 Kontroller

Oyunu Android TV kumandası veya klavye ile rahatlıkla oynayabilirsiniz:

| Aksiyon | TV Kumandası / Klavye |
| :--- | :--- |
| **Sola Git** | ⬅️ Sol Yön Tuşu / `A` |
| **Sağa Git** | ➡️ Sağ Yön Tuşu / `D` |
| **Zıpla** | ⬆️ Üst Yön Tuşu / `OK` Butonu / `Space` |

| **Seçimi Onayla** | `OK` / `Enter` |

## 🛠️ Kullanılan Teknolojiler

* **Dil:** Kotlin & C++
* **UI Framework:** Android Jetpack Compose (Material 3)
* **Derleme & Yapılandırma:** Gradle & CMake (Android NDK)
* **Minimum SDK:** Android 11 (API level 30)
* **Hedef SDK:** Android 16+ (API level 37)

---

## 🚀 Projeyi Derleme ve Çalıştırma

1. Projeyi bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/<kullanici-adi>/BurcinGame.git
   ```
2. **Android Studio** (2024.1+ önerilir) ile projeyi açın.
3. Gradle senkronizasyonunun tamamlanmasını bekleyin.
4. Cihazınızı (Telefon, Tablet veya Android TV/Mi Box) bağlayın ya da bir Android Emülatörü başlatın.
5. `Run` (Çalıştır) butonuna basın veya terminalden derleyin:
   ```bash
   ./gradlew assembleDebug
   ```
